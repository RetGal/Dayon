下载

    Windows 用户最方便的方式是直接从 Microsoft Store 安装。

    支持自行更新、硬件兼容面较广的软件包，可在 Snap Store、 Flathub 以及 ppa:regal/dayon 获取。



    也可以从 GitHub 或 SourceForge 下载适用于你平台的最新安装包。

    Windows： 我们提供两种安装包，便于您快速安装 Dayon!。一种捆绑了基于 OpenJDK 11（LTS）的 JRE，一种则没有。注意：带 JRE 的只适用于 64 位 Windows。
    从 1.9 版起还有两个独立的「快速启动」版，一个是协助端（Assistant），一个是受助端（Assisted）。这两个便携版不用安装（绿色版）， 但为避免Windows用户帐户控制（UAC）可能带来的问题，建议以管理员权限启动（右击-以管理员身份运行）。

    Debian、Ubuntu 及其衍生版： 为确保 Dayon! 自动保持最新版本，建议通过 ppa:regal/dayon 或 snap 安装。
    PPA： sudo add-apt-repository ppa:regal/dayon，sudo apt-get update，最后 sudo apt-get install dayon。
    Snap： sudo snap install dayon。
    手动下载：自行下载.deb安装包后，在终端里用 sudo dpkg -i dayon*.deb 安装。

    Linux：既可以通过 Snap Store 安装会自行更新的 snap 应用，也可以用 sudo snap install dayon 或者用 tar xzvf 解压下载的 .tgz 包。 运行目标目录里的 setup.sh 脚本。已安装的 JRE/JDK 位置会自动检测，tgz 里没有捆绑。 如果检测失败，可以在 dayon.sh 里手动设置 JAVA_HOME。
    注意：.tgz 包只在众多 Debian 和 Ubuntu 版本上测试过。

    macOS/OS X： 打开 .dmg 包，把 受助端（Assisted） 或 协助端（Assistant） 拖到程序图标上。 如有需要，须安装合适的 Java JRE 11（或更新）。
    也可以：把 .tgz 包解压到任意位置。为方便使用，可以为 dayon_assisted.sh 和 dayon_assistant.sh 创建别名，并复制到桌面（同样需要已安装 JRE 11 或更新）。
    重要：从 macOS Catalina 起，必须明确授予屏幕捕获权限： 系统设置 > 隐私与安全性 > 屏幕录制
