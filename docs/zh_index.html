远程协助服务

    Dayon! 是一款开源、跨平台（JAVA）的解决方案，可以查看并控制远程电脑。 某种意义上说，它和现有的远程桌面方案（Teamviewer、Anydesk…）很像。

    但我想，Dayon! 有自己的特色，这正是它的价值所在。 更多细节详见 快速入门。

功能

轻松配置

    Dayon! 专为零计算机基础的用户而设计。终端用户无需配置网络（无需配置防火墙、路由器或 NAT），只需打开 Dayon! 客户端，输入指定地址，即可连接到远程计算机（客户端主动连接服务端）。

低带宽占用

    Dayon! 发送经过压缩和缓存的灰度画面（最多 256 级），尽量少占带宽，在互联网上也能尽量做到接近实时。 这样的画面足以用来看菜单、图标，并了解对方电脑的设置等。

近况（18）

    第 18 版（Gusty Goblin）会在建立连接时按需查询公共 STUN 服务器。也可以另外配置私有 TURN/S 服务器。
    从第 16 版（Eager Eagle）起，如果协助端端口无法被访问，连接会自动反转。
    从第 15 版（Dolly Double）起，远程桌面也可以用彩色传输。
    从第 12 版（Adorable Asteroid）起，Linux 也有了便携版，和 Windows 上已有一段时间的快速启动版类似。
    它们由两个独立文件组成：一个给受助端，一个给协助端。 之所以叫「快速启动」，是因为不用先安装就能直接打开受助端或协助端 （Windows 上的限制：需要 JRE）。它们与常规的 Dayon! 完全兼容。

    请见 完整更新日志

缘起

    Marc Polizzi 在菲律宾生活期间开发了 Dayon!，彼时，他通过 Skype 与远在欧洲的家人、朋友联络。

    他希望能有一款无需任何额外配置（无需设置防火墙、DSL/路由器、NAT 等）即可使用的远程桌面，以便访问家人和朋友的计算机。 因此，他决定利用业余时间开发一款能够适应低带宽和高网络延迟的远程桌面应用——Dayon!。

    多年后，我在 Sourceforge 上寻找免费的跨平台远程协助方案时发现了这个程序。 用 Dayon! 协助运行 Windows 7 及更新系统的用户时，我发现它有一些严重问题。 当时最新版（1.2）还是 2009 年初发布的，于是我联系了作者。 征得他同意后，我于 2016 年底把项目源代码迁到 GitHub ，并接手后续开发。

    顺带一提，Dayon! 在菲律宾当地方言米沙鄢语（Visayas）里是「请进！」的意思。
